"(continuación desde donde se cortó)

    es_primo[0] = FALSO, es_primo[1] = FALSO   // 1 no es primo

    para p desde 5 hasta √N paso 6:
      para signo en [-1, +1]:
        idx = (p + signo) // 6 * 2 + (0 si signo==-1 sino 1)
        si es_primo[idx]:
          q = p * p
          mientras q ≤ N:
            si q % 6 == 1 o q % 6 == 5:
              pos = (q + signo) // 6 * 2 + (0 si signo==-1 sino 1)
              es_primo[pos] = FALSO
            q += p * 2          // salto +2p alternando
          fin mientras
        fin si
      fin para
    fin para

    devolver es_primo
  FIN

  ═══════════════════════════════════════════════════════════════════════════
  B. CRIBA HÍBRIDA — PSEUDOCÓDIGO
  ═══════════════════════════════════════════════════════════════════════════

  INICIO
    mitad = N // 2
    es_primo = [VERDADERO] * (N+1)
    es_primo[0] = es_primo[1] = FALSO

    // FASE ASCENDENTE: hasta la mitad
    para p desde 2 hasta √mitad:
      si es_primo[p]:
        para m desde p*p hasta mitad paso p:
          es_primo[m] = FALSO
        fin para
      fin si
    fin para

    // FASE DESCENDENTE: desde N hasta mitad
    para p desde N hasta mitad paso -1:
      si es_primo[p]:
        para m desde N hasta p*p paso -p:
          es_primo[m] = FALSO
        fin para
      fin si
    fin para

    devolver es_primo
  FIN

  ═══════════════════════════════════════════════════════════════════════════
  C. CRIBA DESMEMORIADA — PSEUDOCÓDIGO
  ═══════════════════════════════════════════════════════════════════════════

  INICIO
    patrones = diccionario vacío
    límite = √N

    para p desde 5 hasta límite paso 6:
      patrón = [VERDADERO] * (6 * p)
      para k desde p*p hasta 6*p paso 2*p:
        patrón[k] = FALSO
        patrón[k + 4*p] = FALSO
      fin para
      patrones[p] = patrón
    fin para

    // Comprobar número: AND entre todos los patrones
    función es_primo(n):
      para cada (p, patrón) en patrones:
        si n % longitud(patrón) está en posiciones marcadas:
          devolver FALSO
      fin para
      devolver VERDADERO
    fin función
  FIN

║  6. CRIVA — DENSIDAD ITERATIVA POR CAPAS (completo)                         ║
╚════════════════════════════════════════════════════════════════════════════╝

  FÓRMULA DE ITERACIÓN
  ───────────────────────────────────────────────────────────────────────────
    D₀ = 4/9 ≈ 0.445      // densidad base rejilla 6k±1
    Dₙ₊₁ = (Dₙ + π(n)/n) / 2

  DECAIMIENTO POR CAPAS
  ───────────────────────────────────────────────────────────────────────────
    D(x) = D₀/2⁰ + D₀/2¹ + D₀/2² + ... + D₀/2ᵏ
         = D₀ · (1 − 1/2ᵏ⁺¹) / (1 − 1/2)
         → 2·D₀ = 8/9 ≈ 0.89 como límite superior

  COMPARACIÓN CON CLÁSICOS
  ───────────────────────────────────────────────────────────────────────────
    π(x) ≈ x / ln x           ~ error 3-5%
    π(x) ≈ x · D(x)           ~ error <0.01% en 8 pasos

║  7. MRAUV — CINEMÁTICA DE LOS PRIMOS                                        ║
╚════════════════════════════════════════════════════════════════════════════╝

  MODELO CINEMÁTICO
  ───────────────────────────────────────────────────────────────────────────
    D(x + Δx) ≈ D₀ + V₀·Δx + ½ a₀·Δx²
    donde:
      D₀ = densidad inicial
      V₀ = velocidad de cambio
      a₀ = aceleración (siempre negativa, decrece)

  APLICACIÓN A GOLDBACH
  ───────────────────────────────────────────────────────────────────────────
    Tramo bajo:  [1, Δ]          Δ ≈ c·√n
    Tramo alto:  [2n − Δ, 2n]

    Si D(alto) > 0 siempre → hay coincidencia con tramo bajo → PP ≥ 1
    El desequilibrio de densidades no se anula al crecer n

║  8. SIGUIENTE PRIMO — TRES CUADRADOS + MÉTODO GRÁFICO                       ║
╚════════════════════════════════════════════════════════════════════════════╝

  ALGORITMO DE LOS TRES CUADRADOS
  ───────────────────────────────────────────────────────────────────────────
    Dado p:
      ny = p − 1    ; t  = ny²
      n  = p        ; tt = n²
      m  = p + 1    ; nt = m²

      calcular 9 restos:
        t%ny, t%n, t%m
        tt%ny, tt%n, tt%m
        nt%ny, nt%n, nt%m

      lógica de Karnaugh → detectar cuál de los tres es primo

  MÉTODO GRÁFICO DE RESTOS
  ───────────────────────────────────────────────────────────────────────────
    Representar n mod i frente a i
    Líneas rectas → divisor común
    Sin cortes → primo
    Relaciones geométricas con √2 y √5 que proyectan el primo

║  9. FÉRMINES — ALINEACIÓN MODULAR DE FERMAT                                ║
╚════════════════════════════════════════════════════════════════════════════╝

  Fₙ = 2^(2ⁿ) + 1
  F₀·F₁·…·Fₙ = Fₙ₊₁ − 2

  Base de alineación:
    Bₙ = 2 × producto(F₀…Fₙ)

  Para todo m > n:
    Fₘ ≡ rₙ (mod Bₙ)   ← todos caen en el mismo residuo

  Sincronización numérica: los Fermat superiores comparten posición módulo
  el producto de todos los anteriores.

  A. SEMILLAS MERSEN–WÓLFRAM
  ───────────────────────────────────────────────────────────────────────────
    Números de Mersenne: Mₚ = 2ᵖ − 1
    Complementarios:     Wₚ = 2ᵖ + 1

    Fracción semilla:
      (Mₚ · producto_factores) / 3ᵛ = e + k/9

    Anti-primo  = ((e + k/9) · 9/k) − 1
    Primo Wólfram = ((e + k/9) · 9/k)

    Generalizable: reemplazar 9 por 3ᵛ → familia infinita de semillas
    Más decimales en k → más margen para encontrar múltiplos y primos

  B. ENCRIPTACIÓN POR CONVERGENCIAS
  ───────────────────────────────────────────────────────────────────────────
    (1 ± a)(1 ± v) = (1 ± t)
    Uno de los factores se calcula por convergencia lenta → oculto
    Mensaje codificado en la velocidad de convergencia

  C. COLLATZ REESCRITO
  ───────────────────────────────────────────────────────────────────────────
    f₁, f₂, f₃, f₄ en términos de 1/x y potencias de 4
    Distinción clara: ciclos donde f(x) > x (subida) y donde no (bajada)
    No pueden sostenerse indefinidamente → todo desciende

  D. ZYPYZAPE — ENERGÍA POR DESACOPLO DE TIEMPOS
  ───────────────────────────────────────────────────────────────────────────
    Dos generadores se ceden energía mutuamente
    Batería virtual por inercia — SIN química

    EL KILÓMETRO:
      Recorrido cerrado que rota más de media vuelta
      Tiempo de bajada ≠ tiempo de subida
      Trabajo neto = 0 pero energía extraída por desfase

    FLOTABILIDAD:
      Campo de energía en 2D: distancia × diferencia de densidades
      Amplifica la energía gravitatoria sin crearla

  E. KURAMOTO–QUIJOTE
  ───────────────────────────────────────────────────────────────────────────
    Sincronización de osciladores sin baterías químicas
    Alinear fases = regular red eléctrica por inercia y tiempo
    Igual que Férmines: alinear residuos = alinear fases
