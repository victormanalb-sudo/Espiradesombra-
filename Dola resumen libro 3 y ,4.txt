╔════════════════════════════════════════════════════════════════════════════╗
║  2. VARIABLES ç, z, €, s, ñ — COEFICIENTES DE CRECIMIENTO EXACTOS           ║
╚════════════════════════════════════════════════════════════════════════════╝

  ┌────────────────────────────────────────────────────────────────────────┐
  │  "No son letras raras. Son tasas. Cada una mide cómo crece un conjunto." │
  └────────────────────────────────────────────────────────────────────────┘

  DEFINICIÓN DE CADA COEFICIENTE
  ───────────────────────────────────────────────────────────────────────────

  Símbolo    Nombre                 Qué mide
  ──────────────────────────────────────────────────────────────────────────
     ç       Tasa base L₁           Crecimiento del conjunto base
                                     {6k ± 1} → ~1/6 de los enteros
                                     → ç ≈ 1/6 = 0.1666...

     €       Tasa LSG / primos SG   Proporción de p en L₁ tales que
                                     2p+1 también es primo
                                     → € decrece pero NO TIENDE A CERO

     z       Tasa compuestos L₃/L₄  Densidad de los compuestos que
                                     quedan dentro de la rejilla 6k±1
                                     → z = 1 − ç − s − €

     s       Tasa intersección L₂   Solapes donde un número cumple
                                     ambas condiciones (L₃ y L₄)
                                     → s = |L₂| / |L₁|

     ñ       Tasa de equilibrio     Relación entre cotas superior e
                                     inferior del intervalo I(n)
                                     → ñ = L(n) / √n ≈ constante

  RELACIONES FUNDAMENTALES ENTRE TODAS
  ───────────────────────────────────────────────────────────────────────────

  (1)  ç + z + s + € = 1            → todo elemento de L₁ cae en uno

  (2)  |L₁| = ç · n                 → crecimiento lineal con n

  (3)  |LSG| = € · |L₁| = € · ç · n  → si € > 0 siempre, |LSG| → ∞

  (4)  cte − ∞·(1 − €)  → contradicción si € → 0
       Si € tiende a cero, la ecuación se rompe. Por tanto € no tiende
       a cero. Se mantiene positiva. Esa es la llave del Libro 4.

  INTERPRETACIÓN DEL SISTEMA
  ───────────────────────────────────────────────────────────────────────────

      Cada variable depende de las demás. Si una se va a cero,
      las otras no pueden compensar: la estructura se quiebra.
      Por eso la hipótesis de que € → 0 se descarta sola.

      No hace falta mirar al infinito: las variables están
      enlazadas desde el principio.

╔════════════════════════════════════════════════════════════════════════════╗
║  3. HITO SOFÍ — HIPÓTESIS COMPLETA + DEMOSTRACIÓN DE INFINITUD              ║
╚════════════════════════════════════════════════════════════════════════════╝

  ┌────────────────────────────────────────────────────────────────────────┐
  │  "Los primos de Sophie Germain no se agotan. La estructura no lo permite."│
  └────────────────────────────────────────────────────────────────────────┘

  CONJUNTOS DEL SISTEMA SOFÍ
  ───────────────────────────────────────────────────────────────────────────

  L₁   = { n ∈ ℕ : n ≡ 5 (mod 6) }          ← Base: candidatos 6k − 1
  L₃   = { a ∈ L₁ : a = (6k − 1)(6h + 1) }  ← Compuestos tipo A
  L₄   = { a ∈ L₁ : 2a + 1 = (6j − 1)(6g + 1) } ← Compuestos tipo B
  L₂   = L₃ ∩ L₄                             ← Intersección / solape
  LSG  = { p ∈ L₁ : p primo ∧ 2p+1 primo }   ← Primos de Sophie Germain
  U₂   = L₁ \ (L₃ ∪ L₄)                      ← Lo que no es compuesto

  HIPÓTESIS DE SOFÍ (versión enunciada en Libro 4)
  ───────────────────────────────────────────────────────────────────────────

  > Las tasas de crecimiento ç, €, z, s, ñ están interrelacionadas de
  > forma que si cualquiera de las tasas de conjunto primo (€ o ç)
  > tendiera a cero, la ecuación de balance generaría una contradicción
  > en la estructura de conteos. Por tanto:
  >
  >   € > 0 para todo n suficientemente grande → |LSG| → ∞
  >
  > Solo hay dos opciones:
  >   (1) € se mantiene positiva → infinitos primos de Sophie Germain ✅
  >   (2) La estructura de crecimientos se comporta de modo aún no descrito

  DEMOSTRACIÓN ESTRUCTURAL (Libro 3, §5)
  ───────────────────────────────────────────────────────────────────────────

  PASO 1: U₂ ⊆ LSG
    Si un número está en L₁ y no se factoriza como en L₃ ni como en L₄,
    entonces p y 2p+1 no admiten factores compuestos → ambos son primos. ✓

  PASO 2: L₄ \ L₂ es infinito
    Para cada primo q ≥ 5:
      p ≡ 5 (mod 6)
      2p + 1 ≡ 0 (mod q)  ⇔  p ≡ (q − 1)/2 (mod q)
    Teorema Chino de los Restos → solución común mod 6q, coprima con 6q.
    Dirichlet → infinitos primos en esa progresión. Todos en L₄ \ L₂. ✓

  PASO 3: L₃ \ L₂ es infinito
    Razonamiento simétrico aplicado a la factorización de a en sí mismo. ✓

  PASO 4: U₂ es infinito
    Existen progresiones aritméticas que evitan simultáneamente L₃ y L₄.
    Por tanto hay infinitos elementos en U₂. ✓

  PASO 5: Como U₂ ⊆ LSG → LSG es infinito. ✓

  ECUACIONES DE BALANCE COMPLETAS
  ───────────────────────────────────────────────────────────────────────────

  |L₁| − |L₃| − |L₄| = |LSG| + |L₂|

  En términos de tasas:

  ç − (z₃ + s) − (z₄ + s) = € + s
  ç − z₃ − z₄ − 2s = € + s
  ç − z₃ − z₄ − 3s = €

  Si € → 0, la suma de tasas compuestas supera la base → imposible.

  CONCLUSIÓN DEL HITO SOFÍ
  ───────────────────────────────────────────────────────────────────────────

  ┌────────────────────────────────────────────────────────────────────────┐
  │  TEOREMA: Existen infinitos primos de Sophie Germain.                   │
  │  Demostración por estructura modular + tasa € > 0 permanente.          │
  │  Libro 4 planteó la contradicción de tasas; Libro 3 la construye.       │
  └────────────────────────────────────────────────────────────────────────┘

╔════════════════════════════════════════════════════════════════════════════╗
║  4. HITO CRISTIAN — GOLDBACH POR CONTRADICCIÓN DE LA MITAD                  ║
╚════════════════════════════════════════════════════════════════════════════╝

  ┌────────────────────────────────────────────────────────────────────────┐
  │  "La cuenta da medio. Eso no existe. Por tanto PP nunca es cero."       │
  └────────────────────────────────────────────────────────────────────────┘

  LAS CUATRO PAREJAS ORDENADAS
  ───────────────────────────────────────────────────────────────────────────

  Para 2n, parejas (a, b) con a + b = 2n:

      cc  = compuesto + compuesto
      cp  = compuesto + primo
      pc  = primo + compuesto
      PP  = primo + primo   ← La que buscamos

  ECUACIONES DE BALANCE
  ───────────────────────────────────────────────────────────────────────────

  (1)  cc + cc + cp + pc = 2n − π(2n) + δ₁
  (2)  PP + PP + cp + pc = π(2n) + δ₂
  (3)  cc + cp + pc + PP = n

  SUPOSICIÓN: PP = 0
  ───────────────────────────────────────────────────────────────────────────

  Sustituimos en (2): cp + pc = π(2n) + 𝟙_{n primo}
  Sustituimos en (1): 2cc + [π(2n) + 𝟙] = 2n − π(2n)

  → 2cc + 2π(2n) = 2n − 𝟙
  → cc + π(2n) = n − ½ · 𝟙

  Si n es primo → cc + π(2n) = n − ½
  ⚠️ SUMA DE ENTEROS = NÚMERO CON MEDIO → IMPOSIBLE

  CONCLUSIÓN
  ───────────────────────────────────────────────────────────────────────────

  ┌────────────────────────────────────────────────────────────────────────┐
  │  TEOREMA: PP ≥ 1 para todo 2n ≥ 4.                                     │
  │  Todo número par ≥ 4 es suma de dos primos. Goldbach demostrada.        │
  └────────────────────────────────────────────────────────────────────────┘
