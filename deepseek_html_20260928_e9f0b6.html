Medición empírica de Refectiva

p = candidatos aceptados / total q = claves reales aceptadas / total claves R = q/p Múltiples filtros Sin trampa Medimos empíricamente si un filtro reduce el espacio de búsqueda o no.

0. Configuración del experimento

Las claves reales se generan aleatoriamente en el espacio. Se prueban varios filtros y se mide p, q, R.

1. Filtros a probar

Cada filtro recibe un candidato \(k\) y devuelve true si pasa, false si se descarta. Se ejecutarán todos sobre el mismo espacio y las mismas claves reales.

Ganancia en bits

Bits ganados = log₂(R). Es la información que el filtro aporta sobre la clave real.

4. Interpretación honesta

Lo que este experimento mide

  • p: fracción del espacio total que pasa el filtro.
  • q: fracción de claves reales (aleatorias) que pasan el filtro.
  • R = q/p: cuánto preserva el filtro la clave real frente al azar.

Lo que este experimento NO mide

  • No mide si el filtro es "seguro" criptográficamente.
  • No mide si el filtro tiene base matemática sólida.
  • No mide si el filtro se puede generalizar a espacios mayores.

La regla

Un filtro solo es útil si R > 1 de forma sistemática y p es pequeño. Si R ≈ 1, el filtro no aporta nada. Si R < 1, el filtro es contraproducente.

Para cualquier filtro basado en propiedades no relacionadas con AES (restos, potencias modulares, mínimos), esperamos R ≈ 1 en el experimento.
