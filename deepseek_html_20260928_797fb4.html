5. Análisis honesto

Qué hace este experimento

  • Precomputa \(g^k \bmod p\) hasta el límite.
  • Guarda la tabla en memoria (Uint32Array).
  • Dado un valor A, busca k por indexación inversa.
  • Detecta el período (el ciclo se repite).
  • Mide tiempo y memoria reales.

Qué límites tiene

  • Memoria: 10⁹ entradas = 4 GB. No cabe en navegador.
  • Tiempo: 10⁹ iteraciones ≈ 10-30 s en JS moderno.
  • Período: si p es pequeño, la tabla se repite. No necesitas 10⁹.
  • Si p es grande: el período puede ser ~p. Tabla de tamaño p.

La regla

Para resolver el DLP por tabla necesitas una tabla de tamaño \(O(\sqrt{p})\) o \(O(p)\), dependiendo del algoritmo. Para \(p = 2^{2048}\) (Diffie-Hellman), necesitas \(2^{1024}\) o \(2^{2048}\) entradas.

Para AES-128, el espacio de claves es \(2^{128}\). Necesitas \(2^{128}\) entradas. Imposible.

Para \(g = 59\) y \(p = 23\), el período es 11. La tabla tiene 11 entradas. Trivial.
